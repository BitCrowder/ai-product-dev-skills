# 调试质量门清单

## 输入与现场

- [ ] 症状、影响、期望/实际、时间范围和至少一个成功对照已记录；未知项有阻断说明。
- [ ] 日志、trace、截图、命令和代码阅读均有来源、采集时间、环境和脱敏边界。
- [ ] 记录了版本、flag、权限、数据、设备/浏览器、网络和近期变更中已知部分。
- [ ] 工作区、允许环境、数据处理和回滚约束已确认；未触碰无关用户改动。

## 证据与推理

- [ ] 每个 `[事实]` 有 `E-*` 或输入原文；每个 `[推断]` 写依据和验证动作。
- [ ] 每个 `[假设]` 都有可证伪预测、优先级依据和反证条件，不以“最可能”替代证据。
- [ ] 最小复现写明前置状态、步骤、失败信号、成功对照和复现率；不能复现时使用观测增强模板。
- [ ] 环境差异矩阵已比较成功/失败样本；未把不同项当成已证实因果。
- [ ] `X-*` 每次只改变一个变量；多变量尝试被降级为线索，不能确认根因。
- [ ] 变更二分记录基线、候选范围、固定条件、步骤与限制；二分命中未被当作根因确认。

## 根因、修复与回归

- [ ] `[已确认根因]` 同时解释症状、环境差异和复现，并有独立或反向实验证据。
- [ ] `[缓解措施]` 与根因修复分开写，包含影响、失效、回滚和撤除条件。
- [ ] 代码修改前有红灯测试/断言或明确的不可复现观测计划；没有并行猜测性改动。
- [ ] 最小修复只覆盖已确认机制；重构、格式化、依赖升级已排除或单独获批。
- [ ] 回归门禁覆盖原始症状、根因不变量、邻近成功对照与适用的环境验证。
- [ ] 每项 `[已运行-*]` 有工作目录、完整命令/动作、时间、退出码/观察、脱敏输出和 `E-*`；`[未运行]` 只有阻断原因。

## 交接与判定

- [ ] 输出包含调试卡、证据/时间线、复现或观测、差异矩阵、假设/实验、二分/机制、根因/缓解和回归门禁。
- [ ] 剩余风险、监控、观察窗口、Owner、回滚与未验证项已明确。
- [ ] **通过：** 根因已确认、最小修复和所有适用门禁有证据。
- [ ] **有条件通过：** 影响已被可回退缓解或部分门禁受外部阻断，且没有把缓解写成根因修复。
- [ ] **不通过：** 症状/证据不足、无法复现且无观测增强、关键假设未验证，或回归门禁缺失；停止修改并交付下一步。
