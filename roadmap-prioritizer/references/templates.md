# 路线图优先级排序模板

## 决策卡、候选项与证据账本

```markdown
# 路线图决定：[周期 / 主题]

## 决策卡
- 要支持的决定、决策人和截止时间：
- 规划周期、目标指标与护栏：
- 容量：按角色列出总量、维护/已承诺工作、强制项和剩余量：
- 不可触碰限制、外部截止时间和非目标：
- [未知] 会改变决定的输入：
```

## 模型选择与评分矩阵

```markdown
## 模型选择
| 可用输入与决定类型 | 选择 / 不选择 | 公式或分类 | 尺度、单位与时间窗 | 边界 |
|---|---|---|---|---|
| | RICE / ICE / Kano / MoSCoW / 自定义 | | | |

## RICE 矩阵
公式：`RICE = (Reach × Impact × Confidence) / Effort`

| ID | Reach（单位 / 周期） | Impact（0.25/0.5/1/2/3） | Confidence（50/80/100%） | Effort（跨职能人周） | 计算 | RICE | 来源、限制与未知 |
|---|---:|---:|---:|---:|---|---:|---|
| | | | | | | | |

## ICE 矩阵
公式：`ICE = (Impact + Confidence + Ease) / 3`。三个字段均为独立整数 `1-5`，不能使用 RICE 的比例或百分比。

| ID | Impact（1-5；目标影响锚点） | Confidence（1-5；证据锚点） | Ease（1-5；交付摩擦锚点） | 计算 | ICE | 各项依据 / [未知] |
|---|---:|---:|---:|---|---:|---|
| | | | | | | |

## 自定义加权评分
公式：`总分 = Σ(标准化准则分 × 权重)`；权重合计 100%。

| ID | 用户价值（1-5） | 战略契合（1-5） | 学习价值（1-5） | 风险/复杂度（1-5，方向已声明） | 权重与计算 | 总分 | 证据与限制 |
|---|---:|---:|---:|---:|---|---:|---|
| | | | | | | | |
```
