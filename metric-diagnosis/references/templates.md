# 产品指标诊断模板

## 诊断卡、数据质量门与变化账本

```markdown
# 指标诊断：[指标 / 决策]

## 诊断卡
- 要支持的决定、负责人和截止时间：
- 指标与业务含义：
- 公式：`分子事件 / 分母事件`；分析单位与去重键：
- 纳入/排除、归因规则、时区与事件时间：
- 当前窗口 / 基线窗口 / 可比日历或季节性基线：
- 数据截至时间、成熟度窗口、数据源和查询/仪表盘版本：
- 可用分群、漏斗、发布/实验/事故和外部事件日志：
- [未知] 会改变决定的输入：
- 结论边界：本报告不能据此断言的因果、未覆盖群体或数据质量结论。

## 数据质量门
| 检查 | 当前/基线证据 | 结果 | 对可比性的影响 | 处理与负责人 |
|---|---|---|---|---|
| 指标口径、去重、筛选、时区、SQL/埋点版本 |  | 通过/失败/未知 |  |  |
| 分子/分母完整性、重复、空值、join 匹配 |  | 通过/失败/未知 |  |  |
| 到达延迟、数据新鲜度、回填、采样 |  | 通过/失败/未知 |  |  |
| 机器人/内部流量、资格与曝光规则 |  | 通过/失败/未知 |  |  |
| 当前/基线的数据成熟度与可比日历 |  | 通过/失败/未知 |  |  |

暂停规则：任一关键检查为失败或未知时，停止业务归因；只交付修复/补数动作和重新诊断条件。

## 变化账本
| 指标/群体 | 当前分子/分母 | 基线分子/分母 | 当前率/基线率 | 绝对人数差 | 百分点差 | 相对变化 | 季节性/可比性说明 | 不确定性/限制 |
|---|---|---|---|---|---|---|---|---|
|  |  /  |  /  |  /  |  |  |  |  |  |
```
