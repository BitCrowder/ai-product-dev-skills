# 安全重构检查清单

## 范围与基线

- [ ] 目标是结构改善；所有新功能、Bug 修复、默认值、错误或时序变化已单列或明确停止。
- [ ] 目标、非目标、工作区基线、允许范围、事实/推断/未知和停止条件均已记录。
- [ ] 每个 `B-*` 有调用方、前置、公开动作、可观察结果和未受影响对照。
- [ ] 现有测试已定位；缺失行为有特征化测试或带限制的替代观测，未运行没有写成已锁定。

## 契约、依赖与性能

- [ ] `C-*` 覆盖 API/schema、数据、事件、配置、权限、错误语义和外部副作用中的适用项。
- [ ] 每个公共改名或删除已查消费者、兼容窗口、迁移/适配、废弃条件和 owner。
- [ ] 输入输出、状态拥有者、I/O、依赖方向、循环风险和可抽取缝隙已审查。
- [ ] 热路径或资源模型可能变化时有 `P-*` 同条件基线、预算和比较；无基线已列 `GAP-*`。

## 步骤与验证

- [ ] 每个 `S-*` 只跨一个边界，分类为机械、语义或功能，并有预期 diff。
- [ ] 机械移动、重命名和格式化未与逻辑/默认值/错误/时序变化混合；无法分开时按语义门槛验证。
- [ ] 每个语义步骤回链 `B-*`、`C-*` 和适用 `P-*`，并在真实命令后记录 `E-*`。
- [ ] 每步后运行目标特征化/契约测试及适用的邻近套件、类型/构建和性能检查。

## 回滚与判定

- [ ] 每一步有最近绿灯 commit、适配层或开关等回滚点；数据与外部副作用的补偿/不可逆边界明确。
- [ ] 出现失败测试、性能越界、未知消费者、依赖反向、范围混入或工作区冲突时停止扩大范围。
- [ ] **通过：** `B-*`、`C-*`、适用 `P-*` 与回滚均有真实 `E-*` 证据，无阻断缺口。
- [ ] **有条件通过：** 仅有披露并接受的非阻断 `GAP-*`，且风险、owner、恢复条件与不扩展范围明确。
- [ ] **停止：** 行为/消费者/性能/回滚不明、失败验证或功能混入未拆分；交付证据与重新开始条件，不继续重构。
