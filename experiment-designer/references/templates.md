## 实验卡、假设与边界

```markdown
# 实验：[名称]

## 实验卡
- 要支持的决定、决策人和最晚决定时间：
- 干预、对照与不在本轮验证的主张：
- 目标人群、纳入/排除条件与风险限制：
- MDE 的价值/成本/风险依据与业务 owner：
- [待确认] 会改变设计或决策的输入：

## 可证伪假设
若对 [人群] 在 [首次曝光事件] 下实施 [干预]，则 [主指标] 在 [归因窗] 相对 [对照] 至少 [提高/降低 MDE]，因为 [机制]。
- 支持预测：
- 削弱/反向预测：
- 替代解释：
- 本实验不能断言：
```

## 预注册、监控与决策

```markdown
## 预注册分析与停止
- 主要比较与主要分析：
- 次要/探索性分析与多重比较处理：
- 异常值、缺失、曝光失败、资格变化与排除：
- 固定样本：最大样本、最短周期、唯一最终检查时间：
- 或序贯/贝叶斯：最大样本、检查节点、效应/无效/伤害边界：
- 统计停止：
- 安全/合规/护栏暂停与回滚：
- 预注册偏离的记录与审批：

## 灰度与监控
| 阶段 | 覆盖人群/比例 | 前置检查 | SRM/数据质量/护栏门槛 | 升级、暂停或回滚 | owner |
|---|---|---|---|---|---|
| A/A 或演练 | | | | | |
| 初始灰度 | | | | | |
| 扩大或 holdout | | | | | |

## 决策规则
- Ship：主指标达到 MDE，区间与预注册方法支持，SRM/污染已解释，护栏未触发，且满足业务限制。
- Iterate：效果或机制信号有价值但未达到阈值，或需要修复可定位的体验/数据问题；写明下一轮改变什么。
- Stop / rollback：护栏、风险或设计失效触发；或达到预定信息量后主要假设不受支持。
- 未完成：到达时间/样本边界但区间仍宽或数据失效；报告为不确定，不把它改写成成功或失败。
```

- 识别前提或研究边界：
- 通过、停止或升级信号：
- 能支持的结论：
- 不能支持的结论：总体效果、长期留存、随机因果效果或其他具体限制。
- 下一步与 owner：
