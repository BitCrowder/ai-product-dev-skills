# 实验设计器使用说明

## 何时调用

在需要决定某个产品改动是否应扩大、继续、停止或先以较低风险方式学习时调用。先说明要支持的决定，不要只说“帮我做 A/B”。

## 最小输入包

未知项可以留空，但必须标为 `[待确认]`：

```text
要支持的决定、决策人、截止时间与不可接受风险：
干预、对照、目标人群、资格与曝光事件：
可证伪假设、主指标、MDE 的价值/成本/风险依据及反向预测：
次要指标、护栏、阈值、观察窗与回滚动作：
基线率/均值、方差、数据延迟、预计合格流量与分流比例：
随机化/分析单位、跨端/团队关系、污染、并行变化及仅在适用时的 ICC/design effect：
显著性、功效、检验方向、最大样本、最短周期、检查和停止规则：
隐私、安全、法务、支持、收入与发布约束：
```

## 推荐执行顺序

1. 先把“想验证是否更好”改写为包含人群、暴露、主要比较、MDE、归因窗和反向预测的假设。
2. 确定随机化单位、分析单位和污染路径，再决定是 A/B、holdout、switchback、灰度、准实验还是定性验证。
3. 只指定一个主指标；将解释性指标列为次要，将伤害边界列为护栏。为每项写公式、资格、去重、窗口和负责人。
4. 在曝光前取得样本估算输入，预注册样本、周期、检查、分析、停止和 ship/iterate/stop 规则。中途只按计划检查数据质量、SRM 和护栏。
5. 上线前做 A/A 或分流演练；上线后按预定节奏记录 SRM、污染、数据延迟、并行变化和护栏，并保留回滚证据。

## 样本与周期缺口

没有基线、方差、MDE、显著性、功效、分流、资格率、预计流量或归因窗时，不能可靠给出单一点样本量或结束日。MDE 还需要业务 owner 的价值、成本和风险依据；没有这些依据时保持 `[待确认]`，不要用随意的百分比填空。工作区随机且主指标为工作区级一次二元结果时，方差可由基线率推得，不需要仅因工作区层级要求 ICC/design effect；只有分析单位低于随机化单位、存在重复观测或额外相关结构时，才补充其估计和来源。

样本满足也不等于可结束：还要覆盖完整业务周期、主指标归因窗和数据延迟。反之，日历截止也不能把尚未完成的试验改写为有效结果。

## 窥探与低流量

普通固定样本设计不能每天看 p 值并在显著时停止。若确需中途判断，必须在曝光前选择序贯或贝叶斯方法，写明最大样本、检查节点和决策边界。安全、隐私、合规、系统稳定性和护栏触发可立即暂停，但这是风险动作，不是统计获胜。

可达样本不足时，灰度和 holdout 用于控制风险；switchback、匹配、差分中的差分或中断时间序列需要满足相应识别前提；原型、假门、concierge、可用性测试和访谈只支持机制或兴趣线索。每种替代方案都要写清能学到什么、不能证明什么及下一步。

## 如何阅读输出

- 主指标决定主要假设；次要指标解释；护栏限制伤害。主指标为正不能覆盖护栏或 SRM 问题。
- SRM、曝光失败、污染、并行变化或预注册偏离会降低因果可信度，必须与效果一起报告。
- 结果应包含绝对差、相对差和不确定区间。显著但低于 MDE 不一定值得投放；不显著且区间宽通常是信息不足。

完整模板见 `templates.md`，交付前运行 `checklists.md`，三种高频情境见 `examples.md`。
