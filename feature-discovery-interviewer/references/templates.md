# 功能探索访谈模板

## 研究卡与假设矩阵

```markdown
# 功能探索访谈：[研究主题]

## 研究卡
- 要支持的决策：
- 研究目标与截止时间：
- 目标用户、分群与工作流：
- 纳入/排除条件：
- 功能想法（若有）：
- 问题假设：
- [假设] 尚未确认的前提：
- [未知] 会改变决定的关键缺口：
- 证据边界：已有材料、未覆盖人群、不能主张的结论。

## 假设证据矩阵
每行必须以参与者编号和逐访谈记录位置直接填写四类证据；没有材料时填 `[未知]`，不能用笼统的“当前证据”替代分类记录。

| 假设 | 支持预测 | 削弱预测 | 替代解释 | `[用户表达]`（参与者/记录位置） | `[实际行为]`（参与者/记录位置） | `[研究者推断]`（支撑证据与范围） | `[未知]`、反例或冲突 | 证据强弱/限制 | 下一步判别动作 |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |
```

## 招募与知情同意

```markdown
## 招募台账
| 分群 | 纳入/排除条件 | 渠道 | 地区/语言 | 激励 | 预计数量 | 已知偏差与缺口 |
|---|---|---|---|---|---|---|

## 开场同意记录
- 本次目的是了解既有工作方式，不是推销或评估受访者：
- 预计时长：
- 是否录音/记录，以及用途、访问范围和保留期限：
- 可跳过问题、拒绝展示资料或随时退出：
- 是否同意继续：是/否；同意的记录方式：
```

## 中立访谈提纲与追问树

```markdown
## 访谈提纲
1. 背景：请介绍你在 [工作流] 中负责什么。
2. 最近事件：请带我回到最近一次你需要 [完成任务] 的时候。从开始到结束发生了什么？
3. 过程：当时先做了什么？用了哪些工具、资料或人？
4. 决策：有哪些选择？为什么用现在的方式？
5. 摩擦与影响：哪一步最费时、容易出错或有风险？如果没有，是什么让它顺利？
6. 替代方案：以前或其他情境怎么做？何时会换一种方法？
7. 反例：最近一次没有遇到这个问题是什么情况？
8. 收尾：还有谁的工作流与此不同，值得访谈？

## 追问树
| 回答类型 | 先问 | 再问 | 停止条件 |
|---|---|---|---|
| 笼统意见 | 最近一次具体是什么时候？ | 当时做了哪些动作？ | 无法回忆或不愿回答时记录未知。 |
| 描述痛点 | 哪一步发生了什么？ | 花了什么、风险是什么、怎样补救？ | 已得到情境、行动、影响和反例。 |
| 提到工具 | 最后一次怎样使用它？ | 为什么选它，何时不用？ | 不要求展示敏感内容。 |
| 赞同功能 | 想到的是哪次实际经历？ | 现有做法哪里不足，哪里已经足够？ | 不将赞同当需求证据。 |

## 不可使用的问法
- 不问：“AI 总结是不是能帮你节省很多时间？”
- 不问：“如果我们上线这个功能，你会不会用？”
- 改问：“最近一次会后你如何记录、回看或交接信息？请按顺序讲讲。”
```

## 逐访谈记录与跨访谈综合

```markdown
## 逐访谈记录
- 参与者编号与分群：
- 招募渠道、激励与已知偏差：
- 同意状态与记录限制：
- 最近事件、时间和情境：
- [用户表达] 原话：
- [实际行为] 动作、工具、替代方案和可安全核对的产物：
- [研究者推断] 支撑证据、适用范围、替代解释：
- [未知] 未问到、记忆不清或冲突处：
- 反例/没有问题的情境：
- 证据强弱：强/中/弱；原因：

## 跨访谈综合
| 主题 | 出现的分群与情境 | 行为证据/原话 | 反例或冲突 | 招募偏差与限制 | 假设状态 | 下一步 |
|---|---|---|---|---|---|---|

## 决策建议
- 可以继续验证：仅列出在已覆盖分群中有足够行为证据的假设。
- 应修订或停止：列出削弱证据与替代解释。
- 不能据此断言：比例、总体优先级、未覆盖分群或因果关系。
- 下一步：方法、目标分群、通过/停止条件、负责人和截止时间。
```
