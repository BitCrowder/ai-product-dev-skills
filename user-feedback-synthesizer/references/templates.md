# 用户反馈综合模板

## 综合卡与来源/去重台账

```markdown
# 用户反馈综合：[产品区域 / 决策]

## 综合卡
- 要支持的决定与截止时间：
- 产品区域、版本与工作流：
- 目标分群与未覆盖分群：
- 反馈单位：原始记录 / 去重反馈事件 / 独立用户（分别计数）：
- 纳入/排除规则与时间窗：
- 渠道构成与样本范围：
- 隐私、匿名化与访问限制：
- [未知] 会改变决定的缺口：
- 证据边界：本报告不能断言的比例、因果、总体需求或路线图决定。

## 来源与去重台账
| 原始记录编号 | 渠道/链接或定位 | 时间 | 匿名作者/账户 | 分群/版本 | 原文或安全摘录 | 纳入状态 | 规范事件编号 | 去重状态与理由 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  | 纳入/排除/待核 |  | 独立/合并/疑似重复；依据、时间窗与例外 |
```

## 编码本与编码记录

```markdown
## 编码本（版本：[日期/编号]）
| 代码 | 定义 | 纳入条件 | 排除条件/反例 | 正例 | 修改记录 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 编码记录
编码置信度：高＝证据与代码定义直接匹配；中＝证据具体但有情境、版本或表述歧义；低＝证据不足、二手或需复核。置信度反映本条的分类把握，不代表主题频率、严重性或优先级。

| 规范事件编号 | 代码 | `[用户表达]` | `[可观察行为/事实]` | `[研究者编码]`（编码本版本） | 编码者/适用规则 | 编码置信度 | `[研究者推断]` | `[未知]`/冲突 | 证据定位 |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  | 编码者；编码本中的纳入/排除规则 | 高/中/低；依据 |  |  | 原始记录编号 + 摘录位置 |
```

## 分群主题、洞察与候选机会

```markdown
## 分群主题表
频率只在同一分群、渠道和时间窗内解释。原始记录、去重事件和独立用户分别报告；不能识别用户时填 `[未知]`。

| 主题 | 分群/情境/版本 | 去重事件（分子/分母） | 独立用户（分子/分母） | 渠道与时间窗 | 严重性证据（不与频率合并） | 支持记录 | 反例/矛盾 | 样本与渠道偏差 | 置信度与限制 |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  /  |  /  |  | 高/中/低/未评估；影响证据 |  |  |  |  |

## 洞察与候选机会
| 已观察主题 | 有边界的洞察 | 不能据此断言 | 问题假设与替代解释 | 候选方案（非承诺） | 下一步验证 | 通过/停止条件 | 路线图仍缺的输入 |
|---|---|---|---|---|---|---|---|
|  | 在 [已覆盖分群/情境] 中观察到… |  |  |  |  |  | 战略、成本、可行性、风险等 |

## 交付结论
- 可立即处理的已知风险（如有）：证据范围、临时缓解与负责人。
- 待验证候选机会：仅列具备证据链与验证路径的事项。
- 不应据此决定：总体比例、未覆盖分群、因果关系、功能承诺或路线图排序。
- 下一步：补样/访谈/日志分析/原型或实验；目标分群、方法、负责人和截止时间。
```
